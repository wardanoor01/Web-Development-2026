The Image Tag

tag is used to add images in an HTML page.

Height and Width Features

We can use the height and width attributes in the tag to specify the height and width of an image.

Displaying a Local Image in HTML

We can display a local image on a webpage by specifying the image file path in the src attribute of the tag.

For Example

The img tag is used to display an image on a webpage. The src attribute specifies the image path, and the alt attribute provides alternative text.
