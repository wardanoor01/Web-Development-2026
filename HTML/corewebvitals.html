Core Web Vitals

Core Web Vitals are a set of Google metrics used to measure the real-world user experience of a web page, especially its loading speed, responsiveness, and visual stability.

There are currently three main Core Web Vitals:
  • LCP (Largest Contentful Paint): Measures loading performance and how quickly the main content of a page loads. To provide a good user experience, LCP should occur within 2.5 seconds of when the page first starts loading.
  • INP (Interaction to Next Paint): Measures interactivity and how quickly a page responds to user interactions, such as clicks and taps. To provide a good user experience, pages should have an INP of 200 milliseconds or less.
  • CLS (Cumulative Layout Shift): Measures visual stability and how much the page unexpectedly moves while loading. To provide a good user experience, pages should have a CLS of 0.1 or less.

Simple Example

A good website should:

  • Load the main content quickly → LCP
  • Respond to clicks quickly → INP
  • Keep the layout stable → CLS
Core Web Vitals help developers understand whether a website feels fast, responsive, and stable to users.
