Tables

The <table> tag in HTML is used to define tables, which are used to format and display tabular data.

<tr> tag: Used to display table row.

<td> tag: Used to display table data.

<th> tag: Used in place of table data for displaying table headers.

Writing '&lt;' and '&gt;' displays the '<' and '>' symbols as text in HTML.

We can define as many table rows as we want. To add a caption to the table, we use tag inside table.

<thead> tag: Used to group the header content of a table, usually containing a <tr> with <th> elements.

<tbody> tag: Used to wrap the table body.

In HTML, we use `<` for `<`, `>` for `>`, and `&` for `&` to display these symbols as text.

Caption: Used to give a title or description to a table.

This attribute is used to create cells spanning multiple columns.
