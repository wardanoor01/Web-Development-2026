Pre Tag

HTML always ignore extra spaces and newlines. In order to display a piece of text as is, we use pre tag.

        This is written
        using pre
        tag

For Example

Using

Tag

Name: Warda Noor Age: 20 City: Faisalabad

Output

Name: Warda Noor Age: 20 City: Faisalabad
Using 
 Tag
    
        Name: Warda Noor
        Age: 20
        City: Faisalabad
    

    
Output

    Name: Warda Noor
    Age: 20
    City: Faisalabad
    
The p tag does not preserve line breaks and extra spaces, whereas the pre tag displays text exactly as written in the HTML code.
